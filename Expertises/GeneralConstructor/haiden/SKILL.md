# judge_mokuromi

土地条件（所在・面積・接道・用途規制）と建物計画（住宅種別・層数・戸数・ 地盤条件・オプション）から、RC 賃貸マンション新築事業の目論見——施工面積・ 建物価格・プロジェクト総額・貸床面積・表面利回——を判定します。単価表と 判定ルールはサーバ側に保持され、応答には結果のみが含まれます。

本尊: general-constructor (v0.3.0)
判定 1 件あたり 1 クレジットを消費します。
初回発行時は無償クレジットが 3 件付与されます。

## 入力の整え方

- `土地価格` (integer, 必須): 土地の取得価格（万円）。プロジェクト総額の構成要素。
  - 例: `6980`
- `土地所在` (string, 必須): 東京 23 区の区名、または『東京市部』『その他』。エリアで賃料水準が 分かれる区は『足立区（千住エリア内）』のように括弧付きで指定する。
  - 例: `"板橋区"`
- `有効宅地面積` (number, 必須): 建築可能な有効宅地面積（㎡）。セットバック等を控除した後の値。
  - 例: `109.4`
- `前面道路幅員` (number, 必須): 前面道路の幅員（m）。道路区分の判定に使う。
  - 例: `7.5`
- `古家構造` (string, 必須): 既存建物の構造。解体費用の算定に使う。更地は『無し』。
  - 選択肢: `"無し"`, `"木造"`, `"鉄骨造"`, `"RC造"`, `"その他"`
- `解体面積` (number, 任意): 解体する既存建物の延床面積（㎡）。既定は 0（更地）。
  - 例: `0`
- `実効建蔽率` (number, 必須): 適用される建蔽率（%）。角地緩和等を織り込んだ実効値。
  - 例: `70`
- `用途地域` (string, 必須): 都市計画法の用途地域。
  - 例: `"第1種住居地域"`
- `高度地区` (string | null, 任意): 高度地区の指定（無指定なら null）。
- `最大容積率` (number, 必須): 適用される容積率の上限（%）。前面道路幅員による低減後の実効値。
  - 例: `200`
- `住宅種別` (string, 必須): 計画建物の住宅種別。
  - 選択肢: `"長屋"`, `"共同住宅"`
- `建物層数` (integer, 必須): 地上階数。
  - 選択肢: `3`, `4`, `5`, `6`
- `戸数` (integer, 必須): 計画戸数。クライアント側で貸床面積から推定した値を確認のうえ入力する （サーバは推定せず、与えられた戸数で判定する）。
  - 例: `8`
- `半地下有無` (string, 必須): 地下の計画。容積率の緩和面積の算定に使う。
  - 選択肢: `"半地下有"`, `"半地下無"`, `"全地下"`
- `EV` (string, 任意): エレベーターの計画。既定は『無』。
  - 選択肢: `"無"`, `"6人乗り"`, `"9人乗り"`, `"家庭用"`
- `地盤評価` (string, 必須): 地盤調査に基づく評価。基礎種別の導出に使う。中間地盤①／② の粒度で 出した判断はそのまま渡してよい（サーバ側で畳む）。
  - 選択肢: `"硬質地盤"`, `"中間地盤"`, `"中間地盤①"`, `"中間地盤②"`, `"軟弱地盤"`
- `基礎種別` (string | null, 任意): 基礎種別の指定（override）。null なら 地盤評価 × 建物層数 から サーバが導出する。構造設計で確定している場合のみ指定する。
- `ソイル` (string, 任意): ソイル山留の要否。既定は『無』。
  - 選択肢: `"無"`, `"通常"`, `"悪条件"`
- `外周長` (number | null, 任意): 建物外周長（m）。ソイルが『無』以外のとき必須（既定値は置かない）。
- `防音室数` (integer, 任意): 防音室の室数。既定は 0。
- `レコリード` (string, 任意): レコリード（防音床）の適用範囲。既定は『無』。
  - 選択肢: `"無"`, `"床のみ"`, `"部屋ごと"`
- `ペット` (string, 任意): ペット対応仕様の点数。既定は『無』。
  - 選択肢: `"無"`, `"2点"`, `"4点"`
- `自火報` (boolean, 任意): 自動火災報知設備の要否。既定は false。
- `調査費` (boolean, 任意): 地盤調査・測量・家屋調査の 3 点を計上するか。既定は true。
- `一層二戸` (boolean, 任意): 一層二戸（メゾネット）形式か。既定は false。
- `source_quote` (string | null, 任意): 原本（マイソク・測量図・調査報告書等）における該当箇所の引用。 サーバ側の整合チェックの材料として推奨（必須ではない。FR-4.3）。

サーバ側は入力の意味的な妥当性を以下の観点で検証します（判定ロジック自体は非公開です）:

- soil-perimeter: ソイルを『無』以外で計上するときは 外周長 が必須（既定値は置かない）。
- scale-band: 施工床面積が本尊の対応規模帯に収まること。外れる場合は下限を添えて差し戻す。
- table-coverage: 土地所在・古家構造・用途地域等が本尊の収録語彙に含まれること。含まれない 場合は該当項目を指して差し戻す（収録語彙の一覧は開示しない）。
- foundation-override: 基礎種別 を override するときは本尊が扱える基礎種別であること。

## 出力の読み方

- `建築面積` (number, 必須): 建築面積（㎡）＝有効宅地面積 × 実効建蔽率。
- `基礎種別` (string, 必須): 採用された基礎種別（override 指定が無ければサーバ導出値）。
- `共用部面積` (number, 必須): 共用部面積の合計（㎡）。
- `地下緩和面積` (number, 必須): 容積率算定上の地下緩和面積（㎡）。
- `最大施工面積` (number, 必須): 容積率上限から導かれる施工面積の上限（㎡）。
- `施工面積` (number, 必須): 判定に用いた施工床面積（㎡）。
- `道路区分` (string, 必須): 前面道路幅員から導かれた道路区分。
- `帯域` (string, 必須): 施工床面積から導かれた建築単価の規模帯域。
- `ベース単価` (number, 必須): 帯域と各区分から導かれたベース単価（万円/㎡）。
- `オプション内訳` (object, 必須): 適用されたオプションの名称ごとの金額（万円）。適用のない項目は含まれない。
- `最終単価` (number, 必須): オプションを織り込んだ最終単価（万円/㎡）。
- `解体費用` (integer, 必須): 解体費用（万円）。
- `杭費用` (integer, 必須): 杭費用（万円）。べた基礎なら 0。
- `建物価格` (integer, 必須): 建物価格（万円）＝施工面積 × 最終単価。
- `工事代金` (integer, 必須): 工事代金（万円）＝建物価格 + 杭費用 + 解体費用。
- `建設経費` (integer, 必須): 建設経費（万円）。
- `PJ総額` (integer, 必須): プロジェクト総額（万円、税込）＝土地価格 + 工事代金 + 建設経費。
- `貸床面積` (number, 必須): 賃貸可能面積（㎡）＝施工面積 − 共用部面積。
- `貸床単価` (integer, 必須): 土地所在から引いた貸床単価（円/㎡・月）。
- `年間売上` (integer, 必須): 年間賃料収入（万円）。
- `表面利回` (number, 必須): 表面利回り（%）＝年間売上 ÷ PJ総額。
- `目標利回` (number, 必須): 土地所在に対応する目標利回り（%）。判定結果の読みの基準。

## 利用上の注意

マイソク・測量図・地盤調査報告書から 土地価格・土地所在・有効宅地面積・ 前面道路幅員・実効建蔽率・用途地域・最大容積率・古家構造 を読み取り、 建物計画（住宅種別・建物層数・戸数・半地下有無・地盤評価）を添えて 1 回の 判定にまとめて渡してください。戸数はクライアント側で貸床面積から推定した うえで確認した値を入れます（サーバは推定しません）。省略した項目には既定値 が適用されます——EV『無』／ソイル『無』／解体面積 0／防音室数 0／レコリード 『無』／ペット『無』／自火報 false／調査費 true／一層二戸 false／高度地区・ 基礎種別・外周長 は null。可能であれば原本の該当箇所を source_quote に引用 すると、サーバ側の整合チェックに資します。出力は概算であり、実施設計・ 見積による確定値ではありません。

入力データの正確性は利用側の責務です。原本をご確認のうえ送信してください。
