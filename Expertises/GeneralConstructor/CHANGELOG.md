# Changelog

## [0.2.0] - 2026-08-24

めぐる標準単価表・修正版（as_of 2026-08-04）への全面置換。**入出力 API・単価水準・税の扱いが揃って変わる破壊的変更**で、v0.1.0 の入力 JSON はそのままでは通らず、出力の数値も比較できない。

### Changed（破壊的）

**入力 API（`ProjectInput`）**
- 退役 7 キー: `搬入経路` / `道路種別` / `接道長さ`（施工条件係数の廃止）、`壁率` / `設備率` / `グレード`（建物形状係数の廃止）、`EV有無`（`EV` へ改称）
- 追加キー: `戸数` / `EV` / `ソイル` / `外周長` / `防音室数` / `レコリード` / `ペット` / `自火報` / `調査費` / `一層二戸` / `基礎種別`（override）。`半地下有無` に `全地下` を追加
- `extra="forbid"` を設定。退役キーを渡すと黙って無視されず検証エラーになる（指定したはずの条件が単価に効かないまま採算判断が出るのを防ぐ）
- `外周長` は `ソイル` ≠ `無` のとき必須（幾何近似での自動補完はしない）

**出力 API（`ProjectOutput`）**
- 退役フィールド: `施工条件係数` / `建物形状係数` / `標準建築単価` / `補正建築単価` / `基礎単価` / `山留工法` / `山留単価` / `基礎費用` / `山留費用` / `地盤費用`
- 追加フィールド: `道路区分` / `帯域` / `ベース単価` / `オプション内訳`（名称 → 万円の写像）/ `最終単価` / `杭費用` / `工事代金` / `PJ総額_税込`
- 基礎・山留は㎡別建てをやめて建物価格へ内包。杭のみ `杭費用` として別建て

**単価モデル（`python/pricing.py` として Domain を分離）**
- 乗算係数モデル（標準単価 × 施工条件係数 × 建物形状係数）を廃し、**帯域基準値 ＋ 道路区分／基礎形状／種別のオフセット ＋ オプション加減算** へ置換
- 丸めは最終㎡単価で一度きり（`ROUND_HALF_UP` 小数 2 桁）。オプション内訳は万円未満を保持

**税・経費**
- 建設経費率 5% → 8%
- 計算は税抜、`PJ総額_税込` を併記（土地は非課税、建物分のみ課税）。`表面利回` は税抜 `PJ総額` ベース

**silent default の廃止**
- テーブル参照の既定値フォールバック（貸床 4400 円・解体 0 万円・基礎 6 万円・建築単価 50 万円/㎡ 等）を全廃。該当行が無ければ `TableLookupError`、定義域外は `PricingDomainError` を送出する
- CLI は Domain 例外（および入力検証エラー）だけを一行に整形して終了コード 1 で返す。それ以外は握らずスタックトレースを出す

### Added
- テーブル 4 本を新設: `建築単価帯域.json` / `単価オフセット.json` / `オプション単価.json` / `定数.json`
- `scripts/xlsx_to_tables.py` — 単価表 xlsx から上記 JSON を生成する変換スクリプト（`openpyxl` は `dev` extra）
- `python/inference.py` — 欠損入力に対する推定値の「提案」（黙って採用はしない）

### Removed
- 退役テーブル 4 本を削除: `施工条件テーブル.json` / `建物形状テーブル.json` / `山留単価テーブル.json` / `山留工法テーブル.json`

### Verification
