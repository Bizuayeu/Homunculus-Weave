# Changelog

## [0.2.0] - 2026-08-24

めぐる標準単価表・修正版（as_of 2026-08-04）への全面置換。**入出力 API・単価水準・税の扱いが揃って変わる破壊的変更**で、v0.1.0 の入力 JSON はそのままでは通らず、出力の数値も比較できない。

### Changed（破壊的）

**入力 API（`ProjectInput`）**
- 退役 7 キー: `搬入経路` / `道路種別` / `接道長さ`（施工条件係数の廃止）、`壁率` / `設備率` / `グレード`（建物形状係数の廃止）、`EV有無`（`EV` へ改称）
- 追加キー: `戸数` / `EV` / `ソイル` / `外周長` / `防音室数` / `レコリード` / `ペット` / `自火報` / `調査費` / `一層二戸` / `基礎種別`（override）。`半地下有無` に `全地下` を追加
- `extra="forbid"` を設定。退役キーを渡すと黙って無視されず検証エラーになる（指定したはずの条件が単価に効かないまま採算判断が出るのを防ぐ）
- `外周長` は `ソイル` ≠ `無` のとき必須（幾何近似での自動補完はしない）

**出力 API（`ProjectOutput`）**
- 退役フィールド: `施工条件係数` / `建物形状係数` / `標準建築単価` / `補正建築単価` / `基礎単価` / `山留工法` / `山留単価` / `基礎費用` / `山留費用` / `地盤費用`
- 追加フィールド: `道路区分` / `帯域` / `ベース単価` / `オプション内訳`（名称 → 万円の写像）/ `最終単価` / `杭費用` / `工事代金` / `PJ総額_税込`
- 基礎・山留は㎡別建てをやめて建物価格へ内包。杭のみ `杭費用` として別建て

**単価モデル（`python/pricing.py` として Domain を分離）**
- 乗算係数モデル（標準単価 × 施工条件係数 × 建物形状係数）を廃し、**帯域基準値 ＋ 道路区分／基礎形状／種別のオフセット ＋ オプション加減算** へ置換
- 丸めは最終㎡単価で一度きり（`ROUND_HALF_UP` 小数 2 桁）。オプション内訳は万円未満を保持

**税・経費**
- 建設経費率 5% → 8%
- 計算は税抜、`PJ総額_税込` を併記（土地は非課税、建物分のみ課税）。`表面利回` は税抜 `PJ総額` ベース

**silent default の廃止**
- テーブル参照の既定値フォールバック（貸床 4400 円・解体 0 万円・基礎 6 万円・建築単価 50 万円/㎡ 等）を全廃。該当行が無ければ `TableLookupError`、定義域外は `PricingDomainError` を送出する
- CLI は Domain 例外（および入力検証エラー）だけを一行に整形して終了コード 1 で返す。それ以外は握らずスタックトレースを出す

**文書**
- 4 本 → 2 本へ統合。`SKILL.md`＝入口・仕様（入出力・アーキテクチャ・機密性・鮮度）、`WORKFLOW.md`＝手順（Phase・判断表・出力雛形）。同じ表を二か所に置かず、相互は参照のみ
- `CLAUDE.md` と `python/README.md` を退役（内容は上記 2 本へ吸収）。単価表の機密性は「将来 Okumiya 本尊へ移す」方針として `SKILL.md` に記載
- 鮮度は各テーブルの `metadata.as_of` を SSoT とし、散文へのカットオフ日付の直書きをやめた

### Added
- テーブル 4 本を新設: `建築単価帯域.json` / `単価オフセット.json` / `オプション単価.json` / `定数.json`
- `scripts/xlsx_to_tables.py` — 単価表 xlsx から上記 JSON を生成する変換スクリプト（`openpyxl` は `dev` extra）
- `python/inference.py` — 欠損入力に対する推定値の「提案」（黙って採用はしない）

### Removed
- 退役テーブル 4 本を削除: `施工条件テーブル.json` / `建物形状テーブル.json` / `山留単価テーブル.json` / `山留工法テーブル.json`
- v0.1.0 の `python/data/建築単価テーブル.json` を削除（loader 非参照の孤児。半地下有無の差分は `オプション単価.json` の「半地下無」へ移管済み）

### Verification

### 追補（2026-08-24 大環主裁定）

上の Changed / Added を本追補が部分的に上書きする。ブランチ未マージのため版は 0.2.0 のまま。

- **税込一本化**: 単価表の数字は**税込**（板橋 case_001 の最終単価 57.05 万円/㎡ が対外表示「平米 57 万円強・税込」と合う）。上記「計算は税抜、`PJ総額_税込` を併記」を廃止し、`PJ総額_税込` フィールド・`calculate_project_total_with_tax`・定数 `消費税率` を削除した（単価表が税込のため使い道が無い）。`PJ総額` と `表面利回` の数値は不変で、意味だけが「税抜」から「税込」に変わる
  - ⚠️ **岡田氏確認事項**: Excel『岡田お試し3』のオプション列見出しは『単価（税抜き）』で、本裁定と食い違う。実装は税込一本で通しており、見出しの訂正可否を確認する
  - 対外表示の単価と `最終単価` は同じ税込基準になったが、設計料の内外は未突合のまま（`WORKFLOW.md` 5.2 の注記を維持）
- **500〜帯の基準値 51 → 52**: `scripts/xlsx_to_tables.py` の `BAND_OVERRIDES` として実装。分解規則の番人（`verify`）は生の xlsx 値で走らせ、その後に裁定分を帯域と golden の双方へ載せる。xlsx 側は 51 のままで、岡田氏が直すまでの乖離は意図的（生成物の `metadata.override` と golden 該当 6 行の `override` が印）
- **敷地系 3 行の数量基準を「敷地面積（有効宅地面積）」へ**: 敷地小規模（80㎡以下）・150㎡以上で立米車・同 中型車。従来の「施工床 × 単価」を改め、`pricing._数量` に `敷地` を追加した
- **cc-defer 解除**: 全地下の地下緩和は半地下と同式で確定（`calculator.calculate_basement_relaxation_area`）。`lookup_foundation_type` の「高層」行に関する cc-defer は対象外で存置
- 変更なしと確定した論点: 分解規則（意図した設計）／長屋の導出帯（妥当）／戸数増減の自動適用（維持）／杭費用は杭本体のみ（二重計上なし）／xlsx の `#REF!`（放置）
